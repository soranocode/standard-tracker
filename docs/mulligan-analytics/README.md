## Контекст для продолжения

Предлагаемая первая версия: встроенный сборщик в Standard Tracker, независимые снимки предложенной и итоговой руки, решения по отдельным экземплярам, результат матча, устойчивое локальное сохранение и отправка, общий сервер на ASP.NET Core с PostgreSQL, доступ участников по приглашениям и таблица статистики в трекере.

Источником данных будут матчи наших участников. Доступ к исторической статистике HSGuru не является зависимостью проекта. Автоматические рекомендации по муллигану и классификация архетипов рассматриваются после накопления и проверки данных.

Ключевые ограничения: различать две копии карты; не включать первый добор в руку после муллигана; не считать пропущенный снимок пустой рукой; не допускать повторного подсчёта при отправке и реконнекте; сохранять точный состав и sideboard; показывать размеры выборок и вклад участников. Существующие снимки `MulliganState` содержат изменяемые `Entity` и требуют копирования значений в момент события.

Чтобы вернуться к этой работе:

```powershell
git switch codex/mulligan-analytics
```

Перед сбором у участников необходимо проверить реальные логи и выбрать сервер для развёртывания. Точки подключения пока исследованы по исходникам; рабочий сборщик ещё не проверялся.
